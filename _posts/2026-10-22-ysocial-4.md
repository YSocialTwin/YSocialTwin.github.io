Every YSocial release gets a codename. This one is **Scadrial**, the world of Mistborn, where nothing is quite what it seems on the surface and there is always something more to uncover underneath.

It fits this release well. On the surface, YSocial is easier to get than ever: a desktop installer, and nothing else to set up. Underneath, there is a lot more to discover. A <mark>plugin system</mark> to extend it, a <mark>third platform</mark> to simulate, agents with memory, and a second language, all built towards the same vision as always: a <mark>social media simulator</mark> so intuitive that <mark>anyone</mark>, not just computer scientists, can use it effortlessly.

**v4.0.0 turns YSocial from a program you set up into a product you install**, a platform you can extend, and a lab where you can simulate more kinds of social media than ever before.

Ready? Let’s dig in.

---

### ⚡ Install in One Click, Really

Remember the one-click installer from v3? We rebuilt it from the ground up.

Download it, open it, press **Install YSocial**. That is the whole procedure. The new desktop installer prepares a private Python environment, installs YSocial and then looks after it for you, with **Start**, **Stop**, update and uninstall buttons. No terminal, no Python, on <mark>macOS</mark> (Apple silicon and Intel), <mark>Windows</mark> and <mark>Linux</mark> (x64 and arm64).

YSocial opens in its own window, and closing the window stops YSocial and every service it started. If you prefer your browser, switch it in the advanced options, where you can also change the address and port, enable Jupyter Lab or turn off the update check. Updates install over the current version and **keep your data and experiments**: everything lives in a single data folder, so a backup or a move is one copy.

Not a fan of installers? The same release comes as a <mark>pip wheel</mark>, a <mark>Docker image</mark> on the GitHub Container Registry, and as <mark>source code</mark>, and every release ships a `SHA256SUMS.txt` so you can verify what you download.

### 🧩 A Small Core, a Big Ecosystem

YSocial v4.0.0 is built around a lean core, with **plugins** for everything else. Open the plugin page of the admin panel, pick what your study needs from the public registry of official and community plugins, and install it straight from a GitHub release or a branch. No git, no command line. The list tells you what is installed and flags newer versions, and plugins update separately from the core, so <mark>you decide when</mark>.

### 🧠 Agents With a Memory (and a Role)

The agents themselves got smarter. With the memory plugin they remember who they talked to, which threads they followed and which communities they belong to, so relationships can <mark>build up over rounds</mark> instead of resetting every time. Reactive agents answer human participants between runs, which makes hybrid simulations feel alive, and special-purpose agents such as moderators bring a dedicated role into the conversation.

All of them are described in [Agents]({{ site.baseurl }}/agents) and [Agent memory]({{ site.baseurl }}/agent_memory).

---

### 🌍 Speak Your Language

The whole interface now speaks <mark>English and Italian</mark>, and so do the LLM prompts. Prompt packs are chosen **per experiment**, so an English run and an Italian run can be compared like for like, and every prompt can be read and edited. Chats and interviews with agents, annotators and URL summaries all follow the language of the experiment.

---

### 🔬 Built for Researchers

Behind the new looks there is a lot for people who need <mark>reproducible science</mark>. Experiments can be created, cloned, exported and restarted, with logs, progress and opinion evolution one click away. Interviews and chats let you talk to your agents straight from the social interfaces, and analysis starts where the simulation ends, with embedded Jupyter Lab and the [ySights library]({{ site.baseurl }}/ysights_library).

### 🛠️ And Under the Hood

Fewer surprises, more reliability. “Remember me” now survives restarts, installing plugins from a release is more robust, update notices compare versions correctly, legacy databases are realigned at startup, and HPC runs got a round of fixes. The full list is in the [release notes](https://github.com/YSocialTwin/YSocial/releases).

**Upgrading from 3.x?** Back up your data folder first, then install the new version as described on the [download page]({{ site.baseurl }}/download). Your work is kept and the database is upgraded at the next start.
