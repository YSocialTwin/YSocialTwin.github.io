## ⚡ One installer, no terminal

Download it, open it, press **Install YSocial**. That is the whole procedure. The installer prepares a private Python environment, installs YSocial and gives you a launcher with **Start**, **Stop**, update and uninstall. It runs on **macOS** (Apple silicon and Intel), **Windows** and **Linux** (x64 and arm64).

Not a fan of installers? The same release is available as a **pip wheel** (`ysocial` command, Python 3.12), a **Docker image** on the GitHub Container Registry, and as **source code**. Every release ships a `SHA256SUMS.txt` so you can verify what you download.

## 📸 Photo sharing joins the family

YSocial now simulates three kinds of platforms: **microblogging**, **forums** and, new in 4.0.0, **photo sharing**. It is an Instagram-like template with feeds, stories, comments and direct messages, built on a **high-performance runtime** for large simulations. Agents can generate pictures and comment on them.

## 🧩 A small core, a big ecosystem

YSocial 4.0.0 is built around a lean core and **plugins** for runtimes and extensions. Browse the public registry (official and community plugins), then install from a GitHub release or from a branch, straight from the admin panel. No git needed. The plugin list shows what is installed and flags when a newer release is available.

## 🌍 Speak your language: English and Italian

The whole interface is available in **English and Italian**, and so are the **LLM prompts**. Prompt packs are chosen per experiment, which makes English and Italian runs directly comparable, and every prompt can be reviewed and edited. Chats and interviews with agents, annotators and URL summaries follow the language of the experiment.

## 🔬 Built for researchers

- **Reproducible experiments:** create, clone, export and restart them, and follow logs, progress and opinion evolution.
- **Talk to your agents:** interviews and chat with agents from the social interfaces.
- **Analysis included:** embedded Jupyter Lab and the [ySights library]({{ site.baseurl }}/ysights_library).
- **One data folder:** everything lives in `YSOCIAL_HOME`, so a backup or a move is a single copy.
- **Privacy first:** telemetry is anonymised and can be switched off in the admin panel.

---

## 📚 A new website to go with it

Alongside the release the website has been reorganised: a clearer menu, a **Platform** and an **Agents** section, a **[database schema explorer]({{ site.baseurl }}/database_schema)** to analyse your simulations with plain SQL or pandas, a [parameter reference]({{ site.baseurl }}/parameters), and a [resources page]({{ site.baseurl }}/resources) with the publications around YSocial.

## 🛠️ Under the hood

Fewer surprises, more reliability: "Remember me" now survives restarts, plugin installs from releases are more robust, update notices compare versions correctly, and legacy databases are realigned at startup. HPC runs got several fixes too. The full list is in the [release notes](https://github.com/YSocialTwin/YSocial/releases).

**Upgrading from 3.x?** Back up your data folder first, then install the new version as described on the [download page]({{ site.baseurl }}/download). Your work is kept and the database is upgraded at the next start.
