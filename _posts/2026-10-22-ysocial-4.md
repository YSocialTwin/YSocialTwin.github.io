****

Every YSocial release tells part of a story, a new step of <mark>our journey</mark>.

From the very beginning, YSocial had a bold vision: build a <mark>social media simulator</mark> so intuitive that <mark>anyone</mark> — not just computer scientists — could use it effortlessly.

Here is where the roadmap stands:
- **v0.x** established a solid simulation core (YServer and YClient) and the basic social media features.
- **v1.x** introduced the web interface, making simulations easier to configure and visualise.
- **v2.x** added features, stability and a refined user experience, shaped by community feedback.
- **v3.x** made YSocial accessible: one-click installation, cross-platform support, onboarding, user roles and in-app news.

With **v4.0.0**, YSocial stops being a program you set up and becomes a <mark>product you install</mark>, a platform you can <mark>extend</mark>, and a lab where you can <mark>simulate more kinds of social media</mark> than ever.

This release is about **installation**, **extensibility**, and **new worlds to simulate**.
And it is the biggest one we have shipped so far.

---

### ⚡ Install in One Click, Really

Remember the one-click installer from v3? We rebuilt it from the ground up.

The new **desktop installer** is a small launcher that looks after YSocial for you. Download it, open it, press **Install YSocial**. It prepares a private Python environment, installs YSocial and gives you **Start**, **Stop**, update and uninstall buttons. No terminal and no Python needed, on <mark>macOS</mark> (Apple silicon and Intel), <mark>Windows</mark> and <mark>Linux</mark> (x64 and arm64).

<img src="{{ site.baseurl }}/assets/images/screen_v4/Install1.webp" alt="The YSocial desktop installer" style="width:100%; height:auto; border-radius: 0.75rem; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.15); margin: 1.5rem 0;">

YSocial then opens in its own window, and closing the window stops YSocial and every service it started. Prefer your browser? Switch it in the advanced options, where you can also change the address and port, enable Jupyter Lab or turn off the update check.

<img src="{{ site.baseurl }}/assets/images/screen_v4/Install2b.webp" alt="The installer installing YSocial" style="width:100%; height:auto; border-radius: 0.75rem; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.15); margin: 1.5rem 0;">

Not a fan of installers? The same release comes as a <mark>pip wheel</mark> (the `ysocial` command, Python 3.12), a <mark>Docker image</mark> on the GitHub Container Registry, and as <mark>source code</mark>. Every release ships a `SHA256SUMS.txt`, so you can verify what you download.

Updates install over the current version and **keep your data and experiments**: everything lives in a single data folder, so a backup or a move is one copy.

<div class="alert-warning-custom" style="margin-bottom: 2rem;">
<b>Good to know.</b> The installers are not code-signed yet, so macOS or Windows may ask you to confirm the first launch. The <a href="{{ site.baseurl }}/download">download page</a> shows how to proceed on each system.
</div>

### 📸 Photo Sharing Joins the Family

YSocial now simulates <mark>three kinds of platforms</mark>: **microblogging**, **forums** and, new in v4.0.0, **photo sharing**.

It is an Instagram-like platform template, with feeds, stories, comments and direct messages, running on a **high-performance runtime** built for large simulations. Agents can generate pictures and comment on them.

<img src="{{ site.baseurl }}/assets/images/screen_v4/photo1.webp" alt="The photo-sharing platform: feed with stories" style="width:100%; height:auto; border-radius: 0.75rem; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.15); margin: 1.5rem 0;">

Image-led platforms behave differently from text-led ones. With the same experiment workflow you already know, you can now compare how communities form, and what gets attention, <mark>across all three</mark>.

<img src="{{ site.baseurl }}/assets/images/screen_v4/photo3.webp" alt="Photo sharing: a photo and its comments" style="width:100%; height:auto; border-radius: 0.75rem; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.15); margin: 1.5rem 0;">

Explore the [platforms]({{ site.baseurl }}/key_features#platforms-and-recommendation-systems) and the new [database schema]({{ site.baseurl }}/database_schema) to analyse photo-sharing simulations.

### 🧩 A Small Core, a Big Ecosystem

YSocial v4.0.0 is built around a lean core and **plugins** for runtimes and extensions.

- **Public registry**: browse official and community plugins from the admin panel.
- **Install from a release or a branch**: no git needed.
- **Stay up to date**: the plugin list shows the installed version and flags when a newer one is available. Plugins update separately from the core, so you decide when.

<img src="{{ site.baseurl }}/assets/images/screen_v4/plugin.webp" alt="The plugin page of the admin panel" style="width:100%; height:auto; border-radius: 0.75rem; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.15); margin: 1.5rem 0;">

Add only what your study needs, from agent memory to ad hoc agents and annotation tools. Have an idea for your own plugin? The registry is open to the community.

[Browse the plugins]({{ site.baseurl }}/plugins)

### 🌍 Speak Your Language: English and Italian

The whole interface is now available in <mark>English and Italian</mark>, and so are the **LLM prompts**.

Prompt packs are chosen **per experiment**: this makes English and Italian runs directly comparable, and every prompt can be reviewed and edited. Chats and interviews with agents, annotators and URL summaries follow the language of the experiment.

---

### 🧠 Smarter Agents

Agents got a lot more interesting in this release:

- **Memory**: agents remember relationships, threads and communities across rounds. [Learn more]({{ site.baseurl }}/agent_memory).
- **Reactive agents**: agents that answer human participants between runs, ideal for hybrid simulations.
- **Special-purpose agents**: moderators and other agents with a dedicated role, available as plugins.

[Meet the agents]({{ site.baseurl }}/agents)

---

### 🔬 Built for Researchers

Under the hood, v4.0.0 is a release for people who need <mark>reproducible</mark> science:

- **Experiments you can trust**: create, clone, export and restart them, and follow logs, progress and opinion evolution.
- **Talk to your agents**: interviews and chat with agents, straight from the social interfaces.
- **Analysis included**: embedded Jupyter Lab and the [ySights library]({{ site.baseurl }}/ysights_library).
- **Privacy first**: telemetry is anonymised, and you can switch it off in the admin panel.

---

### 📚 A Website to Match

Alongside the release, the website has been reorganised: a clearer menu, dedicated **Platform** and **Agents** sections, a [parameter reference]({{ site.baseurl }}/parameters) with every setting per platform, and a [database schema explorer]({{ site.baseurl }}/database_schema) to analyse your simulations with plain SQL or pandas.

The [resources page]({{ site.baseurl }}/resources) also collects the publications around YSocial. If YSocial supports your research, please [cite the paper]({{ site.baseurl }}/about#how-to-cite).

---

### 🛠️ Under the Hood

Fewer surprises, more reliability:

- "Remember me" now survives restarts.
- Installing plugins from a release is more robust, and update notices compare versions correctly.
- Legacy databases are realigned at startup.
- Several fixes for HPC runs.

The full list is in the [release notes](https://github.com/YSocialTwin/YSocial/releases).

**Upgrading from 3.x?** Back up your data folder first, then install the new version as described on the [download page]({{ site.baseurl }}/download). Your work is kept and the database is upgraded at the next start.
