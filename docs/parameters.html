Parameter reference

Every server and client setting of the three platforms: meaning, values, effect and where to set it.

A simulation is configured in layers: the server of each experiment and the client of each population. This page lists the server and client parameters and says which of the three platforms, microblogging, forum and photo sharing, each one applies to. New here? Start from Your first simulation.

All Microblogging Forum Photo sharing platforms the row applies to Advanced behind Show Advanced Parameters Ray / HPC Ray-based simulator

1. Where parameters live

  1. 1Experiment (server)Created in Experiments. One server per experiment.
  2. 2ClientCreated in the experiment. One per population.
  3. 3PopulationAgents, activity profiles, interests, opinions.

Each layer writes a JSON file into the experiment folder when you press Create; the simulators read only these files. If a result surprises you, check them in this order: server file, client file, population file, then logs. Every client also copies the prompt pack, so version it together with the configuration.
