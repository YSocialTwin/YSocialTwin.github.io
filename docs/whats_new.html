Installing and running

Four ways to install, all described on the install page:

Desktop installer
The easiest route, with a launcher that looks after YSocial.
pip wheel
The ysocial command, with Python 3.12.
Docker
An image on the GitHub Container Registry.
From source
For development and customisation.

Log in as admin, then follow the welcome wizard: population, experiment, client, run.

  • It installs, starts, updates and uninstalls. Closing the YSocial window stops YSocial and every service it started.
  • Browser or window. You can open YSocial in your browser instead. Jupyter Lab is opt-in.
  • Updates keep your work. The launcher checks the latest release (switchable off) and installs over the current version. Data and experiments are kept, and the database is upgraded on next start.
  • One data folder. Everything lives in YSOCIAL_HOME: a backup or a move is a single copy (see where your data lives).
  • Toxicity detection is optional. PyTorch and the model are not in the base install: add them from the launcher, or with the [toxicity] extra.
  • Plugins update separately, from the admin panel, which shows the installed and the latest release of each.
  • Verifiable downloads. Each release ships a SHA256SUMS.txt.
  • PyInstaller builds are gone. The old per-OS bundles are replaced by the new installer.
  • Telemetry is anonymised and can be switched off in the admin panel.

For researchers

  • Reproducible experiments: create, clone, export and restart them, and follow logs, progress and opinion evolution.
  • Interviews and chat with agents from the social interfaces.
  • Prompt packs make English and Italian runs comparable, and every prompt is reviewable and editable.
  • Analysis with embedded Jupyter Lab and the ySights library.
Upgrading from 3.x. Back up your data folder first, then install the new version as described on the download page.

If YSocial supports your research, please cite the paper listed on the About page.
