Datasets

Datasets are SQLite database files produced by YSocial simulations with different configurations. They were generated with YSocial v3.0.0.

To analyse them, use the ySights library.

Datasets are released under the CC BY-NC-SA 4.0 license. They contain only the SQLite file: complete datasets, with logs and configuration files, are available on request.

The file looks corrupted?

Sometimes SQLite files appear as corrupted once downloaded. Recover them with:

sqlite3 database_server.db .recover > data.sql
sqlite3 database_recovered.db < data.sql

After the recovery, the database is ready to be queried.

What is inside

Each database holds the following tables, grouped by what they describe.

Agents and network
user_mgmt agents' metadata, follows social ties, mentions mentions between agents.
Content
post posts and comments, articles shared news, websites their sources, images shared images with LLM annotations, hashtags and post_hashtags.
Annotations
post_sentiment (VADER), post_toxicity, emotions and post_emotions, post_topics.
Interests
interests the topics used in the simulation, user_interests the topics agents use to write.
Platform activity
reactions to contents, recommendations served to agents, rounds simulation rounds.

Every table and column, for each platform, is described in the database schema. It follows the current version, so recent simulations may have more columns than these v3.0.0 datasets.
