ySights is a Python library for analysing YSocial simulations, with tools to extract insights from rich agent-based behavioural data.

What it does

  • Easy access to simulation databases (SQLite).
  • Streamlined queries of posts, comments, likes, shares and other interactions.
  • Export for further analysis.
  • Networks of followers, interactions and communities.
  • Temporal evolution of behaviours and structures.
  • Content and sentiment of posts and comments.
  • Agent profiling by activity, influence and engagement.
  • Recommender impact on information spread.
  • Built-in plots straight from analysis results.
  • Timelines of activity.
  • Network graphs of social connections.
  • Statistical summaries of key metrics.

It plays well with Pandas, NumPy and Matplotlib, and it is extensible: write your own analyses and plots.

Built on network science libraries

For network analysis, ySights integrates by design with task-oriented libraries.

DyNetXDynamic networks CDlibCommunity detection NDlibOpinion dynamics ASHHigher-order networks

Get started

Requirements: Python 3.8+, and a YSocial simulation database (SQLite).

1. Install

pip install ysights

2. Analyse

from ysights import YSocialAnalyzer

# Load simulation data
analyzer = YSocialAnalyzer('path/to/database.db')

# Basic statistics
stats = analyzer.get_statistics()

# Network structure
network = analyzer.build_network()

# Activity timeline
analyzer.plot_timeline()

Need data to practise on? Try the datasets. Full documentation is at ysocialtwin.github.io/ysights.
